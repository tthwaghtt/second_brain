# inbox (정제 안 된 세션 메모)

> 날짜: 2026-10-17 · 출처: second_brain 점검 세션 · 근거: 점검.md 4-2(안 B) · 태그: inbox, 쓰기
> **규칙:** 세션은 inbox를 읽지 않습니다. 쓰기만 합니다. 읽고 정리하는 건 따로 여는 컴파일 세션뿐입니다. · **적용 범위:** second_brain을 쓰는 모든 프로젝트

## 1. 쓰는 법

- 세션 끝에 다른 프로젝트에도 통할 교훈이 있을 때만, `inbox/YYYY-MM.md`에 한 줄을 남깁니다.
- 손으로 쓰지 않고 도구로 씁니다(형식이 어긋나지 않게):
  ```bash
  python3 tools/add_note.py inbox --source "AI_LEVELTEST/세션B" --scope "문서가 여러 개인 프로젝트" \
      --what "상태가 네 문서에 따로 있었다" --why "상태 문서가 없어 각자 요약함" --next "STATUS.md 하나만, 나머지는 가리키기"
  ```
- 한 줄 형식: `- 날짜 · 출처 · 범위: … · 무엇: … · 왜: … · 다음엔: …`
- 프로젝트에만 해당하는 숫자나 파일 이름은 쓰지 않고 일반화한 교훈으로 씁니다. 비밀, 개인정보, 고객 정보는 쓰지 않습니다.

## 2. 컴파일 (사용자가 요청할 때)

- inbox 줄을 읽고 중복을 합치고, 일반화해서 `insights/`, `lessons/`, `playbooks/`의 노트로 옮깁니다(`tools/add_note.py`로). 낡은 내용은 취소선과 날짜로 처리합니다.
- 두 번 이상 확인된 규칙은 `skills/second-brain/SKILL.md`에 반영하고 판 날짜를 올립니다. 그다음 사용자가 계정 스킬을 다시 저장합니다.
- 옮긴 줄은 inbox에서 지우지 않고 줄 끝에 `→ 옮김: <노트> (날짜)`를 붙입니다.
