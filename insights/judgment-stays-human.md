# 판단은 사람 몫, AI는 설명과 씨앗까지

> 날짜: 2026-11-19 · 출처: Creazy 바이럴 카드(ist-virerfind)/지휘 · 근거: 경험 · 태그: 판단, 원칙, 기능 설계
> **규칙:** AI는 설명과 아이디어 씨앗까지만 내고, 재미·쓸모·뜬 이유 같은 최종 판단은 사람에게 남긴다. AI가 점수로 골라 판단을 대신하는 기능은 제안하지 않는다 · **적용 범위:** AI가 추천하거나 골라 주는 기능을 만드는 프로젝트, 후보를 내는 모든 일

## 1. 원칙 (도하 원문, 2026-11-17)

<!-- 원문 -->
> "ai에게 내 감과 판단력을 맡기지 않는다."
<!-- /원문 -->

## 2. 왜

- 인스타 영상 정답지를 채점할 때, AI가 유명인·우연·선 넘는 사람 때문에 뜬 영상을 "편집 형식 덕분"으로 보거나 "이유 모름"으로 남겼다.
- AI는 소리를 못 듣고 앞부분 사진 몇 장만 봤다. 유행, 재미, 자극의 세기를 재지 못한다.
- 그래서 도하는 "AI가 상위 몇 편을 골라 주기"를 버리고, "사람이 상위 100편쯤을 넘겨 보며 기준을 스스로 만들기"로 방향을 바꿨다.

## 3. 제안할 때 지킬 것

- AI가 점수로 고르거나 걸러 최종 판단을 대신하는 설계는 피한다. 넓게 보여 주고 설명과 씨앗을 곁들이는 쪽을 추천한다.
- 영상 이해 도구(Gemini 같은 것)는 내용 받아 적기에 쓰고, 재미나 쓸모 판정에는 쓰지 않는다.
- 후보를 낼 때도 같다: AI는 후보와 다른 점을 설명하고, 고르는 것은 사람이다(`playbooks/idea-candidates.md`).

## 4. 사례
