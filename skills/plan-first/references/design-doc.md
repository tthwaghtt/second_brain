# 설계 문서 틀

필요 없는 장은 빼도 됩니다. 길이보다 "빌더가 사용자에게 다시 묻지 않고 계획을 세울 수 있는가"가 기준입니다.

```markdown
# <이름> 설계

> 날짜: YYYY-MM-DD · 상태: 초안, 승인 전 | 승인(YYYY-MM-DD, 원문 위치) · 기준 문서

## 1. 의도와 왜
- 무엇을, 누구를 위해, 왜 지금 (사용자 말 그대로 인용 1~3줄)

## 2. 목표 / 안 할 것 / 실패의 모습
- 목표:
- 안 할 것:
- 실패의 모습(돌아가도 실패인 것):

## 3. 제약
- 기술·시간·돈·법·건드리면 안 되는 것

## 4. 정한 것
| 결정 | 누가 | 근거 |
|---|---|---|
| | 사용자 / 내 판단 | 원문 날짜 또는 이유 |

## 5. 완성 기준 (잴 수 있게)
- [ ] 예: 휴대폰에서 끝까지 12분 이하 (확인: 실측 3회 중앙값)

## 6. 빌더에게 맡기는 것
## 7. 정할 것 (사용자)
```
