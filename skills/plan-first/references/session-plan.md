# 세션 계획 틀

로드맵(기준 문서)에 둡니다. 시작 프롬프트는 여기 쓰지 않습니다(상태 문서에 다음 하나만).

```markdown
# <프로젝트> 세션 계획

> 날짜: YYYY-MM-DD · 설계: <설계 문서 경로> · 상태: 초안 | 승인(날짜)

## 0. 큰 그림
| 단계 | 세션 | 목표 | 사람 확인 지점 |
|---|---|---|---|

## S1. <이름>
- 전제: (앞 세션 산출물, 없으면 "없음")
- 목표: (한 문장)
- 읽을 것: `파일` N장, `파일` M-2장 (꼭 필요한 것만)
- 할 일: 1~5개
- 멈출 곳: (여기서 사용자 확인을 받고 끝냄)
- 완성 기준: - [ ] … (확인: 명령/측정)

## 안 할 것
## 아직 모르는 것 (언제 알게 되나)
```

**크기 가늠:** 세션 하나가 읽을 것 + 만들 것이 새 맥락의 절반을 넘을 것 같으면 쪼갭니다. 서로 독립인 조사는 하위 에이전트로 빼면 본 세션이 가벼워집니다.
