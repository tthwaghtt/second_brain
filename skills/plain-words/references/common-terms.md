# 영어·개발 낱말 공통 표

> 모든 프로젝트 공통. 1장의 말은 그대로 쓰고, 2장의 말은 그 글에서 처음 나올 때 쉬운 뜻을 한 줄로 붙인다. 검사 프로그램은 이 표를 세지 않는다.
> 처음 만든 곳: 인스타 영상 분석 프로젝트(2026-11-16, 도하 승인 13줄). 그래서 몇 줄은 영상 분석 말투로 적혀 있다. 다른 프로젝트에서 뜻이 다르면 그 프로젝트의 용어집(`docs/GLOSSARY.md`)에 적는다.
> 새 낱말을 더할 때: 두 프로젝트 이상에서 도하가 몰랐던 낱말만 여기에, 한 프로젝트 말은 그 프로젝트 용어집에.

## 1. 그대로 쓰는 말 (풀지 않음)

> 2026-11-19 더함. 도하가 이미 아는 개발 용어다. 우리말로 바꾸지 않고(예: 브랜치를 '갈래'로 쓰지 않음), 풀이도 붙이지 않는다. 프로젝트 용어집이 바꾸라고 해도 이 표가 먼저다.

| 말 | 누가 정함 |
|---|---|
| 브랜치, 커밋, push, merge, PR | 도하(2026-11-17) |
| pull, clone, diff, 레포, 훅, 서브에이전트, 스킬, 세션 | AI가 더함(2026-11-19, 도하가 지시문에 그대로 쓰는 말). 도하가 아니라고 하면 `FEEDBACK.md`에 적고 뺀다 |

## 2. 처음 풀 말 (처음 나올 때 한 줄로 풂)

| 말 | 쉬운 뜻 |
|---|---|
| CTA | 영상 끝에서 보는 사람에게 행동을 부탁하는 말이에요(팔로우, 링크 누르기 같은 것). |
| POV | '내가 이 상황이라면' 시점으로 찍은 영상 형식이에요. |
| SaaS | 구독해서 쓰는 인터넷 소프트웨어 서비스예요. |
| SQL · SELECT · INSERT · upsert | 데이터베이스에 묻고(SELECT) 넣는(INSERT) 명령 언어예요. upsert는 '있으면 고치고 없으면 새로 넣기'예요. |
| RLS · 마이그레이션 · 스키마 | 차례로 누가 어느 줄을 읽고 쓰는지 정하는 Supabase 권한 설정 / 표를 만들거나 바꾸는 명령을 파일로 적은 것 / 표에 어떤 칸이 어떤 모양으로 있는지 적은 설계예요. |
| ingest · 크롤 · 스크래퍼 · Apify | 받아 온 결과를 우리 폴더·표로 가져와 저장하는 단계 / 인스타 같은 곳의 정보를 자동으로 긁어 오는 일·도구·서비스예요. |
| MCP · 커넥터 | Claude가 Supabase·Apify 같은 바깥 서비스를 부르는 연결 통로예요. |
| Whisper · VAD | 영상 속 말을 글로 받아쓰는 프로그램 / 말이 있는 구간을 찾는 기술이에요. |
| Haiku · Sonnet · Opus | Claude AI 모델 이름이에요(작은 것 · 중간 · 큰 것). |
| 아웃라이어 · 표본 · 대조군 | 평소보다 크게 튄 것 / 비교에 쓴 개수 / 견주려고 같이 본 '안 터진' 영상이에요. |
| UTF-8 BOM | 엑셀·노션에서 한글이 안 깨지게 CSV 파일 맨 앞에 붙이는 표시예요. |
| 아티팩트 | claude.ai에 올리는 웹 페이지예요. 보고·질문·채점 페이지가 이걸로 나가요. |
