# 상태 문서 틀 (STATUS.md 또는 HANDOFF.md)

흐름 문서입니다. 매번 덮어쓰고 옛 내용은 남기지 않습니다(이력은 git에). 결정 자체는 기준 문서에, 원문은 원문 기록에 두고 여기서는 가리키기만 합니다.

```markdown
# STATUS

> 갱신: YYYY-MM-DD · 세션: <번호/이름> · 커밋: <해시>
> 새 세션은 1·2·6장만 먼저 읽습니다.

## 1. 목표
- 프로젝트: (한 줄, 기준은 <PRD 등>)
- 다음 세션: (한 줄)

## 2. 지금
- 어디까지: (세션 계획의 몇 번까지)
- 돌고 있는 작업: 없음 | <무엇, 어디서 확인>
- 확인한 것: <명령/측정 → 결과>

## 3. 손대는 파일
| 파일 | 장/함수(줄) | 왜 |
|---|---|---|

## 4. 바뀐 것 (이번 세션)
- <무엇> — 왜(원문 날짜 또는 결정 위치) — 커밋 <해시>
- 판단: <무엇> — <왜> — <틀리면 비용>

## 5. 안 된 시도
- <시도> → <왜 안 됐나> → <다음엔>

## 6. 다음 한 걸음
- 다음 세션 시작 프롬프트 (작성: YYYY-MM-DD, 세션 <N>, 다음: 세션 <N+1>, 승인: <원문 위치>)
  > …
- 읽을 것(장 단위):
- 첫 번째 할 일:

## 7. 알려진 문제 / 정할 것
- (기준 문서의 "정할 것" 장을 가리킴. 여기 복사하지 않음)
```
