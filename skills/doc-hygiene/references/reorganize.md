# 파일·폴더를 안전하게 옮기는 절차

> second_brain `playbooks/reorganize-folders.md`(2026-10-16, MAGNUM OPUS 경험)를 옮김. 원본이 바뀌면 brain-compile에서 함께 고칩니다.

## 순서

1. **계획 먼저 보고:** 옮길 자리 그림 + 깨질 수 있는 곳 + 확인 방법. 승인 뒤 시작(옮기기는 큰 결정).
2. **조사:** 파일마다 누가 부르나(`grep -rl 파일이름`), 위치 계산 식(`ROOT = …parent…`, `cd "$(dirname "$0")/.."`), 서로 import, 외부 예약 작업(launchd, cron)이 부르는지.
3. **지금 상태를 먼저 커밋**(되돌릴 기준). 옮기는 중엔 `git stash` 금지(→ `lessons/mistakes.md` 8).
4. **`git mv`로 옮기기**(이력 유지, 지우는 파일 0).
5. **경로 고치기**
   - 문자열 경로 일괄 치환(정규식, 이미 바뀐 것을 또 바꾸지 않게 앞뒤 조건).
   - **조각 경로도 검색:** `"scripts" / "x.py"`, `join(ROOT, "scripts", "x.py")`.
   - 위치 계산 식은 한 단계씩 더하고, **실행해서** 모두 프로젝트 폴더를 가리키는지 자동 확인.
   - 모듈 검색 경로(sys.path)에 새 하위 폴더 추가.
   - 사용자 원문 인용 안의 경로는 바꾸지 않음(원문 보존). 화살표 뒤 내 주석만.
   - 읽기 전용 기록 폴더(archive)는 고치지 않고, 지도에 "옛 경로를 씀"이라고 적음.
6. **확인**
   - 모든 파이썬 `py_compile`, 셸 `zsh -n`/`bash -n`
   - 스크립트를 실제로 실행(`--help`). 옮기기 전과 결과를 비교하려면 **커밋된 이전 버전**과 비교
   - 주요 도구 실제 실행(검사, 페이지 조립, 블렌더 내보내기 같은 무거운 것도 하나는)
   - 문서 검사(장 참조, 파일 경로, 코드 속 경로) 0개
7. **지도 갱신:** 규칙 파일의 문서 자리 표, 인수인계 문서의 폴더 나무, README 목록, 코드 지도, 메모리 속 경로.
8. **모순 점검:** 규칙·지도·README·실제 폴더가 서로 맞는지. 남은 어긋남은 보고.
9. 커밋(무엇을 어디로, 무엇으로 확인했는지) → 원격에 올림.
