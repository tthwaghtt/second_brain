아래는 새 프로젝트 인터뷰의 앞 대화예요. 이어서 AI가 할 다음 답 하나만 써 주세요.

[도하의 첫 요청]
새 프로젝트 하나 시작하려고. 동네 독서 모임 사람들이 다음 모임 날짜랑 읽을 책을 같이 보는 웹을 만들고 싶어.

[인터뷰에서 오간 것 (요약)]
- AI: 누가 쓰나요? → 도하: "우리 독서 모임 8명. 다들 휴대폰으로 볼 거야."
- AI: 지금은 어떻게 하고 있어요? → 도하: "단톡방에 날짜랑 책 제목이 묻혀서 매번 다시 물어봐."
- AI: 무엇이 되면 성공이에요? → 도하: "다음 모임 날짜랑 책을 링크 하나로 바로 볼 수 있으면 돼."
- AI: 이번에 안 만들 것은요? → 도하: "채팅이나 댓글은 필요 없어. 단톡방이 있으니까."
- AI: 가장 세게 묶는 제약은요? → 도하: "돈은 안 쓰고 싶어. 무료로."
- AI: 로그인이 필요할까요? → 도하: "아니, 링크만 알면 보게."
- 조사: AI가 무료로 페이지를 올릴 곳 후보 3개를 출처와 함께 보여 줬고, 도하가 "GitHub Pages로 하자"고 골랐어요.
- 진행 한 줄: 다룸: 왜 ✓ · 누구 ✓ · 성공의 모습 ✓ · 안 할 것 ✓ · 가장 강한 제약 ✓ · 기술 선택 ✓ · 데이터 ✓ · 배포 ✓

[AI의 되짚기]
- 결과: 다음 모임 날짜와 읽을 책을 링크 하나로 보는 휴대폰용 웹 페이지
- 누구를 위해: 동네 독서 모임 8명
- 왜 지금: 단톡방에 날짜와 책이 묻혀 매번 다시 물어봐서
- 성공의 모습: 링크 하나로 다음 모임 날짜와 책을 바로 본다
- 가장 강한 제약: 돈을 쓰지 않는다(무료)
- 안 할 것: 채팅, 댓글, 로그인
맞나요? 고칠 곳 있나요?

[도하의 답]
맞아.
