# RECIPE: 작업 규칙과 지금 단계

> 판 1 · 2026-10-17. 세션마다 자동으로 읽히는 파일입니다. 200줄 이하로 둡니다.

## 0. 세션을 시작하면

1. 필요한 장만 읽습니다: `STATUS.md`의 "★ 지금" → `ROADMAP.md`의 그 세션 항목 → 그 "읽을 것" 장. 통째로 읽지 않습니다.
2. 확인: 최근 커밋, 작업 갈래
3. 이해한 목표와 계획을 짧게 보고합니다.

## 1. 목적

집밥 레시피 책 한 권(사진 포함)을 만듭니다. 기준은 `PLAN.md`입니다.

## 2. 무엇은 어디에

| 사실 | 기준 문서 |
|---|---|
| 무엇을 왜, 정한 것 | `docs/PLAN.md` |
| 지금 상태, 다음 세션 프롬프트 | `docs/STATUS.md` |
| 세션 계획 | `docs/ROADMAP.md` |
| 사용자 원문 | `docs/record/USER_DIRECTIONS.md` |
| 폴더 지도 | `docs/MAP.md` |

## 3. 일하는 방식

- 보고는 한국어로, 쉬운 말로.
- 기획 책임 세션만 `PLAN.md`, `ROADMAP.md`, `STATUS.md`를 고칩니다.

## 4. 건드리지 않는 것

- `refs/`: 사용자가 준 참고 자료
- `docs/record/`: 사용자 원문은 덧붙이기만
